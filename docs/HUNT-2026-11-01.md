# Investigation, November 1, 2026

The initial search returned 125 distinct public repositories: 72 for AnyPS5,
53 for KytyPS5, and none for the alternate KyttyPS5 spelling. Each query was
capped at 100 results. Of those, 120 initial snapshots completed and five
encountered empty-repository errors. The client now handles empty repositories.
This search covers indexed name matches, not every repository on GitHub.

## What the investigation found

Four primary reports identify 25 historical distribution repositories. Their
names, evidence sources and dates are in the [reviewed record](RESULTS.md).
On November 1, 24 returned GitHub HTTP 404, which means unavailable or
inaccessible to the requesting account. It does not prove a takedown.

One named Webrat repository, `themaxlpalfaboy/CVE-2025-54897-LAB`, remained
public. Its inspected head was `d12f0dbd5609312ef960791ab4ef8213aaf3ef33`.
The tree contained a README, a one-byte script, and an 8,924,179-byte archive.
The README still directed visitors to run an executable from that archive.
Kaspersky identifies this exact repository in its Webrat indicators. The
archive's current bytes were not fetched, so this investigation does not claim
independent validation of its current payload.

The two strongest new PS5 provenance leads are documented in
[review-status.json](../src/emuwatch/advisories/review-status.json), with exact
commit references and release digests. One publishes tiny placeholder source
files alongside a much larger build; the other has no source at the inspected
commit despite its open-source claims. Both remain UNKNOWN for malware.

## Earliest source

The AnyPS5 lead's earliest returned commit was October 22, 2026. The KytyPS5
profile lead's earliest returned commit was October 28. These are observation
dates for two repository histories. They do not identify the origin of the
campaign, and Git commit dates can be imported or forged.

The original PS5 coverage attributes the investigation to NordVPN. A public
primary technical report identifying exact malicious PS5 repositories or hashes
was not located in the searches performed here. That evidence gap remains open.
The Minecraft, Webrat, GitVenom and Yoba sources are independent campaign records;
no shared operator with the PS5 operation has been established.

## Changes to the checker

- Primary-source repository warnings work before a network request, including
  for unavailable repositories.
- Twelve exact SHA-256 file indicators can now produce a confirmed warning,
  including six GodLoader files published by Check Point Research.
- Release assets also match against known hashes, even when copied into a
  differently named repository.
- Withdrawn, suspected and false-positive hashes cannot trigger confirmation.
- Profile repositories, small source trees and large release archives are
  inspected for provenance inconsistencies.
- Negative antivirus advice, such as "never disable Defender", is not scored as
  an instruction to weaken protection.
- Scans and community leads persist in an append-only local record. Community
  reports begin as UNKNOWN and require a reviewed data change for publication.

The tool never fetched or executed a release archive during this investigation.
It reads public metadata and text, and preserves hashes and immutable references.

## Reproduce the collection

```powershell
python tools/hunt_round.py --output .local/hunts/round.json
python -m emuwatch history
```

Use an optional public-read GitHub token for larger collections. The tool does
not publish scan logs, credentials, local paths, or private repository contents.
