Security and limits

Ward keeps static inspection separate from optional isolated follow-up analysis.

  • Public HTTPS Git repositories only.
  • No hourly scan allowance. Work is bounded by queue and concurrency limits.
  • Extended scans attach automatic offline REMnux evidence for at most two Windows executables.
  • Windows behavior is offered only while its disposable worker is verified online.
  • MCP accepts repository and SHA-256 scans, not file uploads.
  • Unknown or Inspected never means safe.
